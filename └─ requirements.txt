## Key Files We Created / Changed / Confirmed

### `backend/apps/sports/models.py`

- **Purpose:** Defines the sports‑domain data model.
- **Important fields:**
  - `Sport.name`, `Sport.slug`
  - `Sport.provider_key` – maps a sport to the external odds provider key (e.g. `soccer_epl`)
  - `Sport.is_active`
  - `Tournament.sport` – many tournaments per sport
  - `Match.sport`, `Match.tournament`
  - `Match.home_team`, `Match.away_team`
  - `Match.start_time`
  - `Match.status` – `scheduled`, `live`, `finished`, `cancelled`
  - `Match.home_score`, `Match.away_score`
  - `Match.odds_home`, `Match.odds_draw`, `Match.odds_away`

This model is the core of all sports data used by the odds API and bet settlement.

---

### `backend/apps/sports/providers.py`

- **Purpose:** Abstracts all logic of fetching sports, odds, and scores from an external provider.
- **Methods:**
  - `fetch_sports(sport_key=None)` – returns available sports
  - `fetch_matches(sport_key=None)` – returns upcoming matches with 1X2 odds
  - `fetch_scores(sport_key=None)` – returns completed/live scores
- **Provider classes:**
  - `BaseOddsProvider`
  - `MockOddsProvider` – development / demo data
  - `TheyOddsAPIProvider` – real The Odds API provider
- **Environment variables used:**
  - `ODDS_PROVIDER` (`mock`, `theoddsapi`)
  - `ODDS_API_KEY`
  - `ODDS_SPORT_KEY` (fallback when no per‑sport key is supplied)
  - `ODDS_API_URL` (defaults to `https://api.the-odds-api.com/v4`)
- **Error handling:**
  - HTTP 404 and 422 are treated as "no data available" to avoid crashes
  - `INVALID_PROVIDER_KEYS = {'football'}` is declared because The Odds API has no generic `football` key

This file is **the crucial integration point** for all odds-related work.

---

### `backend/apps/sports/pricing.py`

- **Purpose:** Manipulate raw bookmaker odds into a target overround / margin.
- **Functions:**
  - `_to_decimal(value)` – converts to `Decimal`
  - `_to_odds(probability)` – converts probability back to decimal odds
  - `compute_margin(odds_home, odds_draw, odds_away)` – returns the overround
  - `normalize_odds(odds_home, odds_draw, odds_away, margin=0.05)` – removes source overround and reapplies the configured target margin
- **Handling two‑outcome markets** (e.g. tennis) where a draw may be `None`.

This file is intended to be the seed of a more sophisticated pricing/risk model.

---

### `backend/apps/sports/management/commands/sync_sports.py`

- **Purpose:** Import available sports from the external provider into the `Sport` table.
- **Use:**
  ```bash
  python manage.py sync_sports
  ```
- It skips invalid provider keys (e.g. `football`).
- It reports how many sports were created, updated, and skipped.

---

### `backend/apps/sports/management/commands/sync_odds.py`

- **Purpose:** Fetch upcoming matches and 1X2 odds from The Odds API.
- **Use:**
  ```bash
  python manage.py sync_odds                      # sync all active sports
  python manage.py sync_odds --sport soccer_epl   # sync only one sport
  python manage.py sync_odds --margin 0.05        # override margin parameter
  ```
- It:
  - Loops over active sports that have `provider_key`
  - Skips invalid keys
  - Calls `provider.fetch_matches(sport_key=...)`
  - Normalizes odds using `pricing.normalize_odds`
  - Upserts matches into `Match` model and creates `Tournament` rows when needed

---

### `backend/apps/sports/management/commands/sync_results.py`

- **Purpose:** Pull final scores from The Odds API and settle finished matches.
- **Use:**
  ```bash
  python manage.py sync_results
  python manage.py sync_results --sport soccer_epl
  ```
- It:
  - Looks up a local `Match` by sport + team names + start time
  - Marks finished matches as `FINISHED`
  - Stores `home_score` / `away_score`
  - Calls `settle_bets_for_match(match)` from `apps.bets.services`
  - Skips sports that already have status `FINISHED`

### `backend/apps/bets/services.py`

- **Purpose:** Core business logic for placing and settling singles and parlays.
- Contains:
  - `place_bet(user, match_id, selection, stake)`
  - `place_parlay_bet(user, stake, selections)`
  - `settle_bet(bet, match_result)`
  - `refund_bet(bet)`
  - `settle_bets_for_match(match)`
  - `_credit_affiliate_commission(bet)`
  - Affiliate commission handling on lost bets
  - Parlay settlement and refund handling

This file was added to the chat so that the automatic result synchronization can correctly settle bets.
