Odds Adjustment & Lay Spread

Sets the flat +/- shift added to live API odds ("Odds adjustment") and the distance added to a live back price for the sportsbook's lay reference ("Lay spread"), at up to 4 scopes: global default, one match (all users), one user (all matches), or one user on one match. Most specific wins. A user-level value only ever changes what that one person sees on the sportsbook — it can never affect the shared exchange order book.
