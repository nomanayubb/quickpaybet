Custom Odds — Pricing Overrides

Controls the "back" price source (genuine Pinnacle API vs. frozen custom values, one per selection) and how "lay" is computed (API Lay, Relative Lay, or Custom Lay, also one per selection where custom), at up to 4 scopes: global default, one match (all users), one user (all matches), or one user on one match. Most specific wins. A user-level override only ever changes what that one person sees/is charged on the sportsbook — it can never affect the shared exchange order book.
